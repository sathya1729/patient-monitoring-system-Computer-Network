# Patient Monitoring System (Computer Networks PBL)

A hospital network for a Patient Monitoring System, designed and simulated in Cisco Packet Tracer.

## Overview
- 3 Cisco 2911 routers (with HWIC-2T serial modules) joined by serial links
- 7 Cisco 2960 switches, 10 PCs, 1 printer and 4 servers
- RIP version 2 routing between all subnets
- Web server (patient monitoring portal), DNS server and email server

## How to open the project
1. Install Cisco Packet Tracer 7.0 or above.
2. Download `Patient_Monitoring_System.pkt` from this repository.
3. Double-click the file to open it in Packet Tracer.

## Quick test
- Open PC0, go to Desktop, then Web Browser, and enter http://pms.hospital.com
  (or http://196.168.1.3) to see the patient monitoring portal.
- Open Command Prompt on PC0 and run: ping 196.168.1.3
